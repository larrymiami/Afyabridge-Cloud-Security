## Implemented control surface

v0.7G contains:

- separate Kenya, Ghana, and South Africa regional public edge definitions;
- country-scoped regional external Application Load Balancer components;
- Cloud Run serverless NEG backends;
- dedicated proxy-only Shared VPC subnet contracts;
- reserved country edge IPv4 addresses;
- regional Cloud Armor policies attached to backend services;
- OWASP CRS 4.22 WAF families in preview mode by default;
- per-IP throttling in preview mode by default;
- verbose Cloud Armor and backend request logging;
- country-scoped public DNS managed-zone contracts;
- regional DNS authorizations and Google-managed certificates;
- TLS policy requiring at least TLS 1.2 with a modern profile;
- HTTPS forwarding on port 443;
- permanent HTTP-to-HTTPS redirect behavior on port 80;
- validation intended to reduce accidental cross-country edge misconfiguration.
